Дайындық
  • iPhone-да Health қосымшасы қадамыңды жазып тұруы керек (әдетте өзі жазады).
  • Жоғарыдағы токен мен мекенжайды «Көшіру» батырмасымен алып қой.
1-бөлім · Пәрмен жасау
  1. Shortcuts қосымшасын аш.
  2. Оң жақ жоғарыдан + басып, жаңа пәрмен жаса.
  3. Add Action бас → іздеуге Find Health Samples деп жазып, оны таңда. Сосын: Sample Type → Steps, ал фильтрге Start Date → Today қой (бүгінгі қадам үшін).
  4. Тағы Add Action → Calculate Statistics. Ішінде: Operation → Sum, кіріс ретінде алдыңғы қадамның Health Sample Values нәтижесі тұрсын.
  5. Тағы Add Action → Get Contents of URL. URL жолына жоғарыдағы мекенжайды қой, Show More бас, сосын Method → POST, Request Body → JSON.
  6. Add new field дегенді екі рет бас: біріншісі token (Text) = сенің токенің; екіншісі steps (Number) = Calculate Statistics нәтижесі.
  7. Пәрменге ат бер (мысалы «Qadam») да, Done бас.
2-бөлім · Тексеру
  1. Пәрменді бір рет қолмен іске қос (▶ батырмасы).
  2. Алғаш рет Health-ке рұқсат сұрайды — Allow бас.
  3. Ботты ашып, «Қадам» экранында бүгінгі сан жаңарғанын тексер.
3-бөлім · Автоматтандыру (өзі жіберсін)
  1. Shortcuts-те төменнен Automation қойындысын аш.
  2. + → Create Personal Automation.
  3. Time of Day → уақыт таңда (мысалы 23:59) → Daily.
  4. Әрекет: Run Shortcut → «Qadam» пәрменін таңда.
  5. Ask Before Running дегенді өшір (Run Immediately). Осыдан кейін күн сайын өзі жібереді.
Қаласаң, «Telegram-ды ашқан сайын жаңарсын» деп қоюға болады: тағы бір Automation жаса — App → Telegram → Is Opened → сол «Qadam» пәрменін қос. Токенді ешкімге көрсетпе.
