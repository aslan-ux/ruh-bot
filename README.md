# Spirit — Telegram Mini App + бот

Мини-приложение для сообщества **Spirit**: регистрация участников, главная страница
с ценностями, слоганом и книгой месяца, нижняя панель навигации и админка для
управления книгой и списком участников. Бот и мини-апп работают в одном чате.

## Что уже готово

- **Регистрация** — 6 полей (Аты, Жөні, Әкесінің аты, Почта, Нөмірі, Туған күні).
  - Телефон: выбор страны с флагом и кодом + номер.
  - Дата рождения: выбор дня / месяца / года (на телефоне — нативный «барабан»).
- **Главная** — ценности (Өсу, Тәртіп, Қауымдастық, Мақсат), слоган, карточка книги
  (фото, название, автор, прогресс %).
- **Нижняя панель**: Қадам, Қаржы, **Басты бет** (крупная, по центру), Прогресс, Профиль.
  Разделы кроме главной — заглушки «Бөлім жасалу үстінде».
- **Админка** (`/admin.html`) — сменить книгу (фото/название/автор/прогресс),
  посмотреть список зарегистрированных участников.

Данные хранятся в простых файлах `data/users.json` и `data/book.json` (без базы данных —
проще для старта; позже легко заменить на настоящую БД).

```
│  └─ admin.html          # админка (книга + участники)

```

## Запуск (локально)

**1. Смени токен бота** (важно — старый засвечен)
В @BotFather: `/revoke` → выбери бота → получи новый токен.

**2. Установи зависимости**
```bash
cd tg-miniapp-bot
npm install
```

**3. Подними HTTPS-туннель** (Telegram открывает только https)
```bash
npx ngrok http 3000
```
Скопируй `https://...` адрес.

**4. Настрой `.env`**
```bash
cp .env.example .env
```
Впиши `BOT_TOKEN`, `WEBAPP_URL` (адрес туннеля), придумай `ADMIN_KEY`.

**5. Запусти**
```bash
npm start
```

Открой бота → `/start` → кнопка. При первом входе покажется регистрация,
после — главная страница.

## Админка

Открой в браузере `АДРЕС_ТУННЕЛЯ/admin.html`, введи `ADMIN_KEY` из `.env`.
Там можно задать книгу (фото по ссылке, название, автор, прогресс) и увидеть
всех зарегистрированных участников.

> Назначение книги конкретному участнику уже поддержано в API
> (`/api/admin/assign`) — кнопку в интерфейсе добавим, когда решишь,
> как именно назначать (всем сразу или индивидуально).
